# Tık Tık Fabric

Mobil, dokunmatik mini oyunlarla çalışan fabrika roguelike'ı. Phaser 3 ile web üzerinde geliştirilir, mağaza için Capacitor ile uygulamaya çevrilir.

- Tasarım belgesi ve yol haritası proje dosyalarında: `tasarim-belgesi.md`, `yol-haritasi.md`
- Şu anki adım: **Adım 2 — üretim, kaynaklar ve tur** (`index.html`). Denge değerleri `RULES` ve `PROD` içinde.
